Preguntas frecuentes

Resolvemos dudas comunes

¿Qué es Glassy Music?

Es un cliente de escritorio no oficial para YouTube Music, enfocado en una interfaz moderna, fluida y con estética glassmórfica.

¿Es oficial o está afiliado a Google/YouTube?

No es oficial. Es una aplicación de terceros que utiliza la web de YouTube Music. Respeta los términos de uso según corresponda.

¿Consume muchos recursos?

Está basado en Electron, pero con una UI ligera. El consumo varía según tu sistema y uso. Puedes cerrarla o minimizarla cuando no la uses.

¿Dónde encuentro las releases oficiales?

Revisa el repositorio del proyecto (GitHub) en la sección "Releases" para descargar binarios oficiales y notas de versión.
